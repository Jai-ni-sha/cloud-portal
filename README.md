# Portal ko live karne ke steps (GitHub Pages)
1. github.com par naya PUBLIC repository banao, naam: cloud-portal
2. Is folder ki saari files/folders upload karo (index.html, style.css, ala1, ala2, ala3, ala4, ala5)
3. ala1 folder me apni report.pdf aur screenshot.png daalo (naam bilkul yehi rakho)
4. ala1/index.html me apna Render URL aur GitHub username badlo
5. Repo > Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save
6. 1-2 minute baad link milega: https://YOUR-USERNAME.github.io/cloud-portal/
